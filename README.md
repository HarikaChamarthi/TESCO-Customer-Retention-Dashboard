# TESCO Customer Retention Dashboard

## Project Overview

This project focuses on building an interactive Customer Retention Analytics Dashboard for TESCO using Microsoft Power BI. The objective was to transform customer, transaction, store, and loyalty program data into actionable business insights that help identify customer churn, improve retention strategies, and evaluate loyalty program performance.

The dashboard provides a comprehensive view of customer behavior, retention metrics, customer lifetime value (CLV), and regional store performance to support business decision-making.

---

## Business Problem

Customer retention is one of the biggest challenges in the retail industry. Although TESCO collects large amounts of customer and transaction data, valuable insights often remain hidden without effective analysis.

This project addresses key business questions such as:

- Which customers are at risk of churning?
- Which regions have the highest churn rate?
- Which loyalty tier performs best?
- Which stores require better retention strategies?
- Which customers generate the highest lifetime value?

---

## Project Objectives

- Prepare and clean multiple datasets using Power Query.
- Build relationships between customer, transaction, loyalty, and store datasets.
- Analyze customer churn across different business segments.
- Identify high-value customers using Customer Lifetime Value (CLV).
- Evaluate the effectiveness of loyalty programs and promotions.
- Create an interactive multi-page Power BI dashboard for business users.
